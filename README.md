# 單字小花園 · CVC Game

以 20 頁英文拼讀教材為基礎的兒童網頁遊戲，提供英文語音、跟讀複習、聽音選字測驗與學習日記。

## 開始使用

線上遊戲：https://druidcub.github.io/cvc-game/ 。也可直接用瀏覽器開啟 `dist/index.html`。建議使用提供英文語音的 Chrome、Edge 或 Safari。

也可以將 `dist` 資料夾部署至任何靜態網站服務。GitHub Pages 設為 `main` 分支根目錄，根目錄入口會導向 `dist/`；`.nojekyll` 保留純靜態檔案。

## 功能

- 20 個字族範圍勾選、母音群組選取，可練習 10／20／全部單字。
- 跟讀複習：英文發音、慢速朗讀、字尾色彩提示。
- 聽音選字測驗：立即回饋、錯字自動收藏、完成成績；至少需要兩個不同單字。
- 星星口袋：收藏不熟悉的單字、一鍵複習、收藏範圍測驗、學會後移除。
- 成長日記：練習日期月曆、複習與測驗紀錄、JSON 匯出備份。
- 語音設定：選擇裝置英文聲音及朗讀速度。
- 童趣花園風格、手機與桌面響應式介面、鍵盤操作。

## 資料與儲存

`dist/data.js` 包含教材的示範單字與練習單字，共 182 個頁內不重複的單字項目。教材特殊項目 `pam`、`ren`、`lunch` 預設不納入練習，可自行勾選加入；保留教材大小寫及 `lunch` 的原頁次。

英文朗讀使用瀏覽器 Web Speech API，需由裝置提供英文語音。複習卡片可主動開啟麥克風跟讀，以辨識出的主要單字和目標單字比對；忽略大小寫、標點，並接受 ten 的數字表示 10。這是辨識輔助，不能判斷每個音素的準確度，也不提供口說分數。短單字、同音字及兒童聲音可能辨識錯誤。紀錄与收藏保存在目前瀏覽器的 `localStorage`，不同裝置與網站網址各自記錄，不會同步到 GitHub。清除網站資料會移除紀錄，建議定期匯出日記。

完成一個跟讀單字或回答一題即儲存進度，中途離開會記錄為未完成。測驗每題僅能回答一次；答錯會顯示答案並收藏。每題可點按喇叭重聽。

## 專案結構

```text
cvc-game/
├── dist/
│   ├── index.html    # 網頁入口
│   ├── style.css     # 花園風格與響應式版面
│   ├── data.js       # 20 頁教材單字資料
│   └── app.js        # 語音、練習、測驗及紀錄
├── .gitignore
└── README.md
```

無需安裝套件或建置。Google Fonts 無法載入時會使用裝置字型。

## 麥克風跟讀

首次使用會顯示家長說明與同意按鈕，接著由瀏覽器詢問麥克風權限。每次最多收音 8 秒，可隨時停止；切換頁面、下一個單字或播放示範發音會停止辨識。不支援語音辨識的瀏覽器仍可使用聽讀與測驗。此功能需支援 SpeechRecognition／webkitSpeechRecognition 的瀏覽器與 HTTPS 或 localhost。

語音辨識可能由瀏覽器的遠端服務處理，需網路連線。本遊戲不儲存錄音及辨識文字、不傳到 GitHub。辨識不一致不會自動判定孩子念錯或加入星星口袋。

## 驗證

執行 node tests/speech.test.cjs 可驗證單字比對規則。語音服務與實際兒童聲音的辨識準確度需在孩子的裝置上實測。

## PWA 與離線使用

公開遊戲支援安裝至主畫面。首次連線開啟後，等待上方顯示「已備妥離線練習」。Service Worker 會快取遊戲畫面、程式、20 頁單字與圖示，之後可離線開啟，並使用複習、聽音選字測驗、星星口袋、成長日記與匯出。離線聽音需装置提供本機英文語音，請先試聽；麥克風辨識需網路。不支援本機語音時仍能看字複習。

Android／電腦可點「安裝遊戲」或瀏覽器的安裝選項；iOS Safari 使用分享 → 加入主畫面。瀏覽器可能對安裝條件與資料保存有不同限制，安裝後請先連線開啟一次。清除網站資料會移除紀錄與離線快取。

新版本下載完成後顯示「更新遊戲」。按下後才重新載入，保留已完成的練習紀錄；本輪尚未完成的單字會重新選題。發布修改時需更新 sw.js 的 VERSION。快取名稱包含專案路徑，清理不影響同網域其他專案。

離線快取驗證：node tests/pwa.test.cjs。首次下載必須全部成功才會顯示離線就緒。

## 記住下拉選單

練習數量（10／20／全部）、英文聲音與朗讀速度會在變更當下保存至一年有效的功能 Cookie，並備份於原本的 localStorage。重新整理、重開網頁或 PWA、返回首頁或切換字族時會恢復選擇。既有的聲音與速度設定會沿用。若裝置暫時沒有先前選擇的語音，畫面改用自動聲音，但保留原選擇以便語音重新可用時恢復。Cookie 只包含選單偏好，不含錄音或日記。清除網站資料、Cookie 過期或使用不同瀏覽器／隔離的 PWA 儲存環境時可能需要重新選取。
